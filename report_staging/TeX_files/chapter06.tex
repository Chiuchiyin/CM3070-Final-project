\chapter{Conclusion}
This project implemented the stock-market Financial Advisor Bot specified by \textbf{CM3020 Artificial Intelligence, Project Idea 2}. The system validates market data, forecasts short-horizon behaviour, forms constrained allocations, evaluates them chronologically and explains results in a Shiny application. \texttt{AdvisorService} connects these functions while keeping language generation downstream of quantitative decisions.

The offline MVP includes ESN forecasting, transparent baselines, an approved legacy FinRL A2C policy, a cost-aware backtester, local Qwen3/Smolagents explanations, deterministic fallback behaviour and 51 passing tests. FinRL achieved the highest cumulative return in the reported interval, while equal weight had stronger risk-adjusted metrics. Forecast-ranked allocation did not beat simple baselines, demonstrating why evaluation must include negative evidence.

The broader lesson is that an AI financial interface should expose the chain from data to decision to evidence. A fluent explanation cannot repair a weak forecast, and a high historical return does not establish future reliability. The next step is a versioned current dataset and an untouched multi-seed evaluation. Live trading, automatic retraining and personalised regulated advice should remain outside scope unless stronger safeguards are added.
