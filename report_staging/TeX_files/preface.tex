\\chapter*{Abstract}\\addcontentsline{toc}{chapter}{Abstract}
Retail investors face volatile markets, large information flows and limited access to transparent portfolio analysis. This project develops an agentic financial advisor for stock-market active portfolio management. The system validates OHLCV data, produces forecasts, converts them into constrained long-only allocations, evaluates them through chronological backtesting, and explains results in a Python Shiny interface. Reservoir computing and FinRL are investigated as model components, while forecast-ranked allocation provides the production path. Qwen3 and Smolagents are optional language components that explain validated service results; a deterministic explanation is used when the local model is unavailable.

The offline MVP includes data preparation, forecasting, strategies, backtesting, an orchestration service, a Shiny application, an approved legacy FinRL A2C artifact and automated tests. On the held-out period from 1 July 2020 to 30 November 2021, FinRL achieved a 71.60\\% cumulative return, compared with 53.44\\% for equal weight, 52.85\\% for buy and hold and 46.36\\% for forecast-ranked allocation. These are historical results, not promises of future performance. The configured 2025 untouched-period experiment remains deferred because the tracked dataset ends in 2021.
